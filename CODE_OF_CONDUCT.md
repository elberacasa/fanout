# Code of conduct

## The short version

Be decent. Assume the other person is trying to do good work. Critique code, not people. No harassment, personal
attacks, or demeaning comments about anyone's identity, background or experience level.

This project reviews a lot of machine-written code, which means a lot of pointing out mistakes. Do it the way you
would want yours pointed out: name the problem, show the evidence, suggest a fix.

## The full version

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in issues, pull requests, discussions and any other project space.

## Reporting

Report unacceptable behaviour to the maintainer through a private channel: GitHub's private vulnerability reporting
form or a direct message. Reports are handled confidentially, and the maintainer will say what action was taken.
Responses range from a private word to a permanent ban, depending on severity and pattern.
